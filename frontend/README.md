# 🎨 TeamHub Frontend Client

Modern Realtime Kanban Web Application built with **React**, **TypeScript**, **Vite**, **TailwindCSS**, **Shadcn UI**, **Socket.IO-client**, and **TanStack Query**.

## 🚀 Getting Started

### 1. Environment Setup
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```
Ensure `VITE_API_BASE_URL` points to your backend:
- Local Development: `http://localhost:4000/api`
- Production (Vercel): `https://teamhub-backend-api.onrender.com/api`

### 2. Install & Run
```bash
npm install
npm run dev
```

### 3. Build & Lint
```bash
npm run lint
npm run build
```
