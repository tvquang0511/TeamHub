## Level 4 — Code / Design Pattern Diagram
> **Mục tiêu**: Đi sâu vào mã nguồn của thành phần kỹ thuật nổi bật nhất hệ thống — **Smart AI Breakdown Engine** được xây dựng theo mẫu thiết kế **Strategy & Chain of Responsibility (Fallback Fault-Tolerance)**.

```mermaid
classDiagram
    direction TB
    
    class IAiProvider {
        <<interface>>
        +name: string
        +generateSubtasks(title: string, description: string): Promise~string[]~
    }

    class DeepSeekProvider {
        +name: string = "deepseek"
        +generateSubtasks(title, desc): Promise~string[]~
    }

    class GeminiProvider {
        +name: string = "gemini"
        +generateSubtasks(title, desc): Promise~string[]~
    }

    class GroqProvider {
        +name: string = "groq"
        +generateSubtasks(title, desc): Promise~string[]~
    }

    class OpenAIProvider {
        +name: string = "openai"
        +generateSubtasks(title, desc): Promise~string[]~
    }

    class AiService {
        -providers: Map~string, IAiProvider~
        -fallbackChain: string[]
        +registerProvider(provider: IAiProvider): void
        +breakdownTask(title: string, description: string, mode: string): Promise~string[]~
        -executeWithFallback(title: string, description: string): Promise~string[]~
    }

    IAiProvider <|.. DeepSeekProvider : Implements
    IAiProvider <|.. GeminiProvider : Implements
    IAiProvider <|.. GroqProvider : Implements
    IAiProvider <|.. OpenAIProvider : Implements
    AiService o-- IAiProvider : Manages Provider Chain
```
